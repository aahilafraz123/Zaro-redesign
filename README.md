# Zaro Redesign

Redesign of Zaro.

## Dev setup

Project-scoped MCP servers live in `.mcp.json` (shadcn, Chrome DevTools) and load
automatically when you open this folder in Claude Code. The `gpt-taste` design skill
is checked in under `.agents/skills/gpt-taste` (symlinked into `.claude/skills`).

```bash
npm install
```
